# Hand-Free-Game

**4시 40분의 용사**는 귀여운 초등학교 선생님이 교실 몬스터를 물리치는 한국어 방치형 RPG입니다. 소개 화면에서 남교사 또는 여교사를 선택하고 모험을 시작하면 자동 공격과 경험치 획득이 이어집니다. 실명 입력이나 가입은 필요하지 않습니다. 서버나 빌드 과정 없이 정적 파일로 실행합니다.

공개 게임: https://gmlduqzhd123-lab.github.io/Hand-Free-Game/

## 로컬 실행

저장소 루트에서 Python 3로 HTTP 서버를 실행합니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/`을 엽니다. 소리는 사용자 조작 후 시작하며, 자동 백업 복사는 HTTPS 또는 localhost에서 사용할 수 있습니다. 복사가 허용되지 않아도 백업 코드를 직접 복사하거나 파일로 내려받을 수 있습니다.

## 검증

저장·전투·PRD v5 수용 회귀 테스트는 Node.js에서 추가 패키지 없이 실행합니다.

```bash
node --test tests/bug-save.test.js tests/character.test.js tests/expansion.test.js tests/game.test.js tests/bug-combat.test.js tests/hold-input.test.js tests/prd-v5.test.js
```

브라우저 검증에는 Python Playwright와 Chromium이 필요합니다. HTTP 서버를 실행한 상태에서 다음 명령을 사용합니다.

```bash
python3 tests/browser_smoke.py http://127.0.0.1:8000/ --output /tmp/hand-free-browser-results.json
```

특정 검사만 실행할 때는 `--check` 필터를 반복 지정할 수 있으며(일치하는 검사가 0건이면 실패로 처리), 시각 검수용 캡처는 `--screenshots` 디렉터리를 지정해 생성합니다.

## 게임과 저장 규칙

- 접속하면 소개와 선생님 선택 화면이 먼저 나타납니다. 시작 버튼을 누른 뒤 무료 자동 공격 Lv 1로 전투와 경험치 획득을 시작합니다. 기존 세이브에서 자동 공격을 아직 열지 않은 경우에도 무료로 시작합니다. 두 캐릭터의 능력은 같으며 선택 화면으로 돌아와 외형을 바꿀 수 있습니다. 선택 화면에서 대기하는 동안 전투와 경험치는 진행되지 않습니다.
- 처음 시작하는 이용자를 위해 첫 3분 온보딩 안내 카드(자동 전투 관찰, 첫 강화, 스킬 사용, 업적 확인)를 제공하며 언제든 건너뛰거나 시스템 탭에서 다시 열 수 있습니다.
- 전투 화면이나 선생님을 마우스로 누르거나, 전투 화면에 포커스를 두고 Enter·Space를 누르고 있으면 추가 공격을 연속 실행합니다. 강화·아이템 구매·유물 뽑기도 `1회` 구매 모드에서 같은 방식으로 반복합니다. 첫 실행 후 280ms부터 약 100ms 간격으로 반복하며, 손을 떼거나 화면·탭을 바꾸면 멈춥니다. 모바일은 길게 누르기로 반복하며 스크롤 동작은 공격이나 구매로 처리하지 않습니다.
- 성장 탭과 상점 탭에서 `1회`·`10회`·`최대` 묶음 구매 단위와 `방치 중심`·`직접 공격 중심` 추천 배너를 제공하며, 모든 강화 버튼에 구매 전후 효과 변화와 부족한 골드를 함께 표시합니다.
- 시스템 탭의 조건부 자동 강화 도우미는 전면 활성 화면에서만 최대 1초에 1회 작동하며, 지정한 골드 예산 상한(`budgetLimit`)과 최소 보유 골드(`reserveGold`)를 엄격히 준수합니다.
- 보스 진입 모드를 `자동 진입` 또는 `준비 후 도전`으로 전환할 수 있습니다. 준비 대기 상태에서는 보스 격파 예상 시간과 필요 자동 공격력을 안내하며, 시간 만료 시 남은 체력과 추천 보완 행동을 진단 카드로 표시합니다.
- 현재 모험의 100·200·300·400구간 보스 돌파에 따라 모험 지역 5곳(`햇살 교실`·`도서관 숲`·`과학실 연구소`·`운동장 하늘길`·`노을빛 학교 정문`)과 추가 동료 4명(`도서부원`·`과학부원`·`음악 요정`·`정리 요정`)이 해금됩니다. 최대 2명의 동행 슬롯, 2종의 동료 조합 시너지, 3개의 프리셋을 지원합니다.
- 5개 슬롯 15종의 캐릭터·교실 꾸미기(복장·소품·지휘봉·배경·장식)를 제공하며, 전투 수치에는 어떠한 보너스도 주지 않습니다.
- 골드 아이템 24종을 최대 Lv.25까지 강화할 수 있습니다. 유물은 기존 4종을 포함한 20종이며 보석 10개로 미보유 유물만 받습니다. 업적은 기존 5개를 포함한 30개이며 진행률 막대, 최대 3개 목표 고정, 미수령 보상 일괄 수령(`모두 받기`)을 지원합니다.
- 자리비움은 최대 24시간의 자동 성장과 전투를 정산합니다. 경험치는 100%, 전투 골드는 70%를 지급하며 최근 10건의 복귀 정산 보고서 열람과 1200×1200 PNG 모험 기록 카드 저장을 지원합니다.
- 연수 정산 대화상자에서는 정산 전후 연수학점·공격력 배율·유지/초기화 항목을 비교하며, 확인 중 보스 만료 등으로 진행 상태가 바뀌면 최신 수치로 재확인을 요청합니다.
- 기존 저장 키 `ys_bugfree_final_v2`를 유지하고 구버전(v1~v4) 데이터를 v5로 변환할 때 첫 저장 직전에 `TeacherRPG_Save_v4_backup` 사본을 보존합니다. 손상된 저장은 원본 보관과 복구 안내를 제공하며 자동으로 덮어쓰지 않습니다.

## 파일과 배포

`index.html`, `styles.css`, `presentation.css`는 화면과 반응형 디자인, `save.js`는 저장 스키마(v5) 검증과 탭 소유권, `catalog.js`는 아이템·유물 정의와 보너스, `adventure.js`는 모험 장소·동료·시너지·꾸미기 정의, `progression.js`는 묶음 구매 견적·추천·보스 예측·복귀 보고서·정산 계획, `automation.js`는 조건부 자동 강화 엔진, `catalog-ui.js`와 `experience-ui.js`는 상점·모험·대화상자 UI, `game.js`는 전투·업적·성장, `app.js`는 연타·브라우저 이벤트·화면·소리·이펙트, `sw.js`는 오프라인 프리캐시를 담당합니다.

상세 요구사항은 [docs/PRD.md](docs/PRD.md), 작업 인계 및 검증 기록은 [docs/HANDOFF.md](docs/HANDOFF.md), 수정 목록은 [CHANGELOG.md](CHANGELOG.md)에 기록했습니다.
