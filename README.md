# Hand-Free-Game

**4시 40분의 용사**는 귀여운 초등학교 선생님이 교실 몬스터를 물리치는 한국어 방치형 RPG입니다. 소개 화면에서 남교사 또는 여교사를 선택하고 모험을 시작하면 자동 공격과 경험치 획득이 이어집니다. 실명 입력이나 가입은 필요하지 않습니다. 서버나 빌드 과정 없이 정적 파일로 실행합니다.

공개 게임: https://gmlduqzhd123-lab.github.io/Hand-Free-Game/

## 로컬 실행

저장소 루트에서 Python 3로 HTTP 서버를 실행합니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/`을 엽니다. 소리는 사용자 조작 후 시작하며, 자동 백업 복사는 HTTPS 또는 localhost에서 사용할 수 있습니다. 복사가 허용되지 않아도 백업 코드를 직접 복사하거나 파일로 내려받을 수 있습니다.

## 검증

저장·전투 회귀 테스트는 Node.js 24에서 추가 패키지 없이 실행합니다.

```bash
node --test tests/*.test.js
```

브라우저 검증에는 Python Playwright와 Chromium이 필요합니다. HTTP 서버를 실행한 상태에서 다음 명령을 사용합니다.

```bash
python3 tests/browser_smoke.py http://127.0.0.1:8000/ --output /tmp/hand-free-browser-results.json
```

Windows, macOS, Linux의 설치된 Chrome·Edge·Chromium 또는 Playwright 브라우저를 자동으로 찾으며 `CHROMIUM_PATH`로 실행 파일을 지정할 수 있습니다. 제공된 HTTPS 프록시가 있으면 사용하고 TLS 검증을 유지합니다. 결과 JSON과 종료 코드로 성공 여부를 확인합니다. 실제 사용자 저장 데이터를 사용하지 않고 새 브라우저 컨텍스트에서 실행합니다.

## 게임과 저장 규칙

- 접속하면 소개와 선생님 선택 화면이 먼저 나타납니다. 시작 버튼을 누른 뒤 무료 자동 공격 Lv 1로 전투와 경험치 획득을 시작합니다. 기존 세이브에서 자동 공격을 아직 열지 않은 경우에도 무료로 시작합니다. 두 캐릭터의 능력은 같으며 선택 화면으로 돌아와 외형을 바꿀 수 있습니다. 선택 화면에서 대기하는 동안 전투와 경험치는 진행되지 않습니다.
- 전투 화면이나 선생님을 마우스로 누르거나, 전투 화면에 포커스를 두고 Enter·Space를 누르고 있으면 추가 공격을 연속 실행합니다. 강화·아이템 구매·유물 뽑기도 같은 방식으로 반복합니다. 첫 실행 후 280ms부터 약 100ms 간격으로 반복하며, 손을 떼거나 화면·탭을 바꾸면 멈춥니다. 모바일은 길게 누르기로 반복하며 스크롤 동작은 공격이나 구매로 처리하지 않습니다.
- 골드 아이템 24종을 최대 Lv.25까지 강화할 수 있습니다. 추가 공격·자동 공격·경험치·골드·치명타·보스 시간에 각기 다른 효과를 줍니다. 유물은 기존 4종을 포함한 20종이며 보석 10개로 미보유 유물만 받습니다. 업적은 기존 5개를 포함한 30개이며 각 보상을 한 번만 수령할 수 있습니다.
- 플레이어 기본 경험치는 매초 5씩 오릅니다. 경험치 아이템·유물의 보너스는 분수 경험치까지 보존됩니다. 첫 기본 레벨업은 약 4초 뒤이며, 다음 레벨에 필요한 경험치는 `20 + (현재 레벨 - 1) × 10`입니다. 레벨마다 전체 공격력 배율이 5%씩 증가하고, 상단에서 레벨과 경험치를 확인할 수 있습니다.
- 자동 공격은 초당 한 번, 반짝 분필 스킬 공격은 활성 화면에서 80ms마다 실행합니다. 느린 프레임에도 경과 시간을 보존합니다. 칭찬의 마법은 10초간 추가 공격의 치명타 확률을 100%로 만듭니다.
- 자리비움은 최대 24시간의 자동 성장과 전투를 정산합니다. 경험치는 100%, 전투 골드는 70%를 지급하며 처치·단계·보스 보상은 같은 전투 규칙을 사용합니다. 수동·반짝 분필 공격은 자리비움에 포함되지 않습니다. 재접속 자체에 추가 경험치를 지급하지 않습니다.
- 보스 제한 시간과 스킬 쿨다운은 실제 시간으로 흐릅니다. 일반 적의 저장 HP를 복원합니다. 16:40 달성 후에도 계속 진행할 수 있습니다.
- 다음 모험에서도 플레이어 레벨·경험치, 연수학점, 보석, 상점 아이템 강화, 유물, 달성 업적과 누적 클릭·보스 처치를 보존합니다. 완전 초기화는 확인 후 실행하며 추가 수집·구매 이력을 지우고 레벨 1과 무료 자동 공격으로 시작합니다.
- 기존 저장 키 `ys_bugfree_final_v2`를 유지하고 v1~v3 데이터를 v4로 변환합니다. 손상된 저장은 원본 보관과 복구 안내를 제공하며 자동으로 덮어쓰지 않습니다.
- 한 탭이 진행을 저장합니다. 다른 탭은 일시 정지되며 명시적으로 이어하기를 선택할 수 있습니다. 저장 실패를 안내하고 유효하지 않은 백업·실패한 가져오기·초기화로 기존 진행을 바꾸지 않습니다.
- 장기 진행의 수치 상한은 `1e100`, 강화 레벨은 1,000, 진행·클릭·처치 카운터는 `1e9`입니다. 크리티컬 확률의 상한은 50%입니다.

## 파일과 배포

`index.html`, `styles.css`, `presentation.css`는 화면과 반응형 디자인, `save.js`는 저장 검증과 탭 소유권, `catalog.js`는 아이템·유물 정의와 보너스, `catalog-ui.js`는 상점·수집 화면, `game.js`는 전투·업적·성장, `app.js`는 연타·브라우저 이벤트·화면·소리·이펙트를 담당합니다. 파일은 같은 위치에서 로딩됩니다.

따뜻한 교실 일러스트와 왼쪽 선생님·오른쪽 몬스터, 마법 투사체와 공격·처치·레벨업 동작으로 모험을 표현합니다. `assets/`의 그림은 원본 SVG로 제공하며 외부 이미지 서비스에 의존하지 않습니다. 졸음 슬라임·낙서 유령·먼지 뭉치·종이 박쥐·장난 도깨비와 각 보스는 서로 다른 모습을 갖습니다. 모션 줄이기 설정을 존중합니다.

모바일에서는 큰 전투 장면과 읽기 편한 글씨를 유지하며 아래로 스크롤해 스킬·강화·설정을 사용할 수 있습니다. 태블릿·PC는 전투와 성장을 좌우에 배치하고, 자세한 규칙은 각 탭의 도움말에서 확인합니다. 효과음은 부드러운 음량과 짧은 멜로디를 사용합니다. 기존 저장 키와 강화·동료·유물·업적·스킬 내부 식별자와 기본 전투 규칙을 유지합니다. 신규 수집과 경험치 보너스는 선택 필드로 저장하므로 예전 백업도 가져올 수 있습니다. 소개와 게임 하단에 저작권을 표시합니다.

GitHub Pages는 `main` 브랜치의 저장소 루트에서 배포합니다. 검증된 변경을 `main`에 푸시한 뒤 Pages 빌드의 성공과 공개 URL의 실제 내용을 확인합니다. 브라우저 테스트 명령의 URL을 공개 주소로 바꾸면 배포본도 검증할 수 있습니다.
